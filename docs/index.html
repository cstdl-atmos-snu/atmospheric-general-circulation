How this site works

Slides

Each lecture's slides open in the browser (reveal.js). Use → / ← or Space to move, F for full screen, Esc for an overview, ? for all shortcuts.

Notebooks

Jupyter notebooks let you reproduce and explore what we discuss in class. Click Open in Colab to run one in your browser with nothing to install, or run them locally (see below).

Exercises

Most notebooks end with a few open-ended questions in the spirit of the textbook's asterisked exercises. Bring your results and questions to the next class.

Running the notebooks on your own computer

If you prefer a local setup, install Miniforge and create the course environment once:

git clone https://github.com/cstdl-atmos-snu/atmospheric-general-circulation.git
cd atmospheric-general-circulation
conda env create -f environment.yml
conda activate agc
jupyter lab

The notebooks read reanalysis data directly from public servers (NOAA PSL OPeNDAP), so no data download is needed for the early weeks.
